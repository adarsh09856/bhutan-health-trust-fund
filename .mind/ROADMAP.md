## Constraints

- Do NOT change the stack from TanStack Start/Router — routing is file-based and tightly coupled
- Do NOT remove the in-memory fallback — it enables offline demos without PostgreSQL
- Do NOT add a REST API layer — all data flows through server functions
- Do NOT edit `routeTree.gen.ts` — auto-generated by the router plugin
- Donation reference numbers (`BHTF-DON-XXXXXX`) are immutable once issued
- All inquiry status transitions are one-directional (`UNREAD → ... → ARCHIVED`)
- TypeScript must always pass `tsc --noEmit` with 0 errors before any commit
