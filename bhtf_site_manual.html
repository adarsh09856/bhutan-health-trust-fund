01

Platform Architecture & Executive Overview

The Bhutan Health Trust Fund platform is a sovereign financial and public transparency portal established to sustainably finance 120+ essential medicines, universal childhood vaccines, and alpine cold-chain logistics across all 20 Dzongkhags.

The platform operates on two interconnected layers:

  1. Public Sovereign Web Portal — provides citizens, international donors, and healthcare providers with live impact metrics, 6-stream procurement tracking, interactive Dzongkhag maps, DRC tax deduction calculators, and instant donation verification.
  2. Admin Control Studios — a secure back-office suite of specialized studios for managing pledges, confirming bank deposits, monitoring cold-chain inventory, issuing tax receipts, publishing audits, and configuring website pages.
⚡ Public Reflection Architecture
All admin actions commit directly to the central PostgreSQL database. When a record is updated (e.g. a donation is verified or a news release published), server cache tags are immediately revalidated. Changes reflect instantaneously across all public routes without needing a manual build or code deployment.

Accessing the Admin Control Center

/admin/login · /admin/dashboard

Logging into the Admin Suite

  1. Open your browser and navigate to https://your-domain.com/admin/login.
  2. Enter your Secretariat email address (e.g. admin@bhtf.bt) and secure password.
  3. Click Authenticate & Access Studio.
  4. Upon verification, you are routed directly to the Executive CRM Dashboard.

Admin Navigation Layout

All administrative tools are structured within a 4-tier navigation sidebar:

  • Executive & Operations — CRM Dashboard, Donors & Pledges, Citizen Inquiries, Subscribers Desk, Commodities & Formularies, Procurement Tenders, National Impact Metrics.
  • Institutional CMS & Media — Pages & Templates, Live Page Studio, News & Bulletins, Reports & Audits, Policies & Charters, Field Operations Gallery, Public Videos.
  • Governance & Community — Board of Trustees, Sovereign Milestones, FAQs Helpdesk.
  • Platform Infrastructure — Staff Logins & RBAC, Security Audit Logs, System & Emergency Settings.

Visual Live Edit Mode & Admin TopBar

/admin/page-editor?slug=[page]

Staff members with content editing privileges can edit public pages while browsing the live website.

Using the Sticky Admin TopBar

  1. Log into the Admin Panel, then browse to any public page (e.g. /, /about, /our-work, /reports).
  2. Notice the dark Sovereign Admin Bar pinned to the top of your screen displaying your active slug.
  3. Click the golden button: ⚡ Live Edit This Page.
  4. The system launches the Visual Live Page Studio with that page preloaded in the visual editor.

In-Studio Controls

  • Device Preview Bar — Switch between Desktop (100%), Tablet (768px), and Mobile (375px) viewports to verify responsive appearance.
  • Block Reordering — Drag blocks up or down to rearrange layout sections.
  • Visibility Toggle — Eye icon allows hiding a section temporarily without deleting its content.
  • Publish vs Draft — Changes remain in draft mode until you click Save & Publish Live.
⚡ Public Reflection Point
Clicking Save & Publish Live in the studio writes directly to the custom_pages table. The public page (e.g. / or /about) instantly updates to serve the new section blocks.

Donors & Pledges CRM (1:1 RGOB Sovereign Match)

/admin/donations

Manages all public and corporate contributions made via RMA BFS gateway, Razorpay, or direct Bank of Bhutan / Druk PNB / BNB bank transfers.

Verifying Offline Bank Transfers

  1. Navigate to Executive & Operations → Donors & Pledges.
  2. Filter by Pending Verification.
  3. Click on the donor's transaction entry to view bank deposit slip, journal number, and donor details.
  4. Cross-verify the payment with the Secretariat's Bank of Bhutan (BoB) deposit ledger.
  5. Click Approve & Reconcile Donation.
⚡ Public Reflection Points
When a donation status changes from Pending to Verified:
1. Corpus Numeral Increases: The public counter on the homepage and hero card automatically adds the donor's amount + the 1:1 RGOB matching sum.
2. Public Receipt Verification: The donor can immediately enter their Journal/Reference ID on /track-donation to download their official sealed DRC 100% Tax Exemption Certificate.

Essential Medicines & 6 Commodity Procurement Streams

/admin/programs

Maintains the primary health formulary and funding allocations across Bhutan's six statutory healthcare commodity streams.

The 6 Statutory Streams

  • Stream 1: Universal Childhood & Maternal Vaccines (14 National Antigens).
  • Stream 2: 120+ Vital Essential Medicines Formulary (Zero stockout buffer).
  • Stream 3: Alpine Solar Cold Chain Logistics (Solar refrigeration & temperature loggers).
  • Stream 4: Primary Diagnostic Reagents & Screenings (Blood glucose, Hepatitis, Pap/HPV).
  • Stream 5: Clean Delivery Kits & Maternal Survival Packs (Remote obstetric health).
  • Stream 6: Emergency Disaster Stockpile & Infusion Reserves (Critical IV fluids).

Editing a Commodity Stream

  1. Click Edit Stream on any commodity card.
  2. Update the annual allocated amount (e.g. Nu. 68,500,000), beneficiaries count, or gewog coverage.
  3. Click Save Stream Changes.
⚡ Public Reflection Points
Updates made here reflect on:
1. /our-work — full interactive commodity formulary cards.
2. / (Homepage) — Commodity Tracker pipeline & Hero Corpus Card supply stream rows.

Security Audit Trail & Fiduciary Compliance Logs

/admin/audit-logs

An immutable, tamper-evident security ledger recording every administrative action taken inside the system.

Audit Ledger Contents

Every log entry captures:

  • Timestamp (ISO 8601 local Bhutan time).
  • Staff Email & User ID who executed the action.
  • Action Category (e.g. DONATION_VERIFIED, TENDER_PUBLISHED, PAGE_SECTION_SAVED, BANK_ACCOUNT_MODIFIED).
  • Client IP Address and browser user agent.
  • Old vs New State Payload (JSON diff).
The audit trail cannot be edited or cleared by any administrator. It is exported annually for inspection by the Royal Audit Authority (RAA) auditors.

Disaster Recovery, Database Backups & VPS Maintenance

Automated Database Backups

The database automatically backs up daily to encrypted storage. To run a manual on-demand backup on the production VPS server:

npm run db:backup

Backup archives are timestamped and stored in .backups/ with full PostgreSQL dump files.

Zero-Downtime Deployment

To deploy new system updates without interrupting citizen services:

  1. Connect to the server via SSH.
  2. Run: git pull origin main
  3. Run: npm run build
  4. Reload the process via PM2: pm2 reload bhtf-server
Database credentials and server SSH keys are confidential sovereign assets. Store all environment variables securely and never commit .env files to public repositories.
