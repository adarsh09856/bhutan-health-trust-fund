Mobile, Tablet & Desktop Responsiveness

The entire public site has been engineered to be 100% device-friendly across phones (iOS/Android), tablets, and widescreen desktop monitors.

📱 Mobile View (360px - 640px)

• Floating Header shrinks gracefully with an instant-tap slide-out drawer.
• Heavy animations auto-disable on mobile to save battery and ensure silky-smooth 60fps scrolling.
• All stat numerals and commodity tabs reflow into vertical, touch-friendly swipe blocks.

💻 Tablet View (641px - 1024px)

• 2-column bento grids for statistics and news items.
• Dzongkhag region selector wraps smoothly with full finger-tap targets.
• Dual action buttons format horizontally without text truncation.

🖥️ Desktop View (1025px+)

• Full panoramic layout with monumental Fraunces serif typography.
• Interactive floating sovereign endowment corpus card.
• Full multi-level dropdowns for institutional governance archives.

⚡ Sticky Admin Bar Responsiveness

• Features a collapse chevron (ChevronUp) that tucks the bar away into a neat bubble on small screens so admins can preview real mobile phone layouts effortlessly.

Admin Portal Workflow & Navigation

Sign in at /admin/login using your authorized email and password.

1. Executive Telemetry

The dashboard displays 4 key cards: verified public contributions, statutory RGOB doubling, combined purchasing yield, and unverified backlogs.

2. Reconciling Pledges

Go to Donors & Pledges CRM. When an offline bank transfer is confirmed by Bank of Bhutan, click Verify. The system automatically issues a DRC tax voucher link.

3. Answering Citizen Inquiries

Navigate to Citizen Ombudsman. Read messages from gewog health clinics or citizens, click Mark In Progress or Resolved.

4. Security Audit Logs

Every admin update (login, publish, policy change) creates an immutable record in Security Audit Trail with IP address and timestamp.

Live Visual Page Customizer Guide

Empowers non-technical staff to build and modify pages dynamically.

⚡ Launch from Public Site

While signed in as an admin, click "⚡ Live Edit" on the top bar of any page. You are immediately taken to the customizer for that specific page.

Switch between Desktop (100%), Tablet (768px), and Mobile (375px) in real time to verify responsiveness before publishing.

🧱 Managing Blocks

Use the Inspector sidebar to edit headlines, Dzongkha subtitles, button URLs, and background styles (Modern White vs Sovereign Dark).

💾 Instant Live Save

Clicking Save & Publish pushes changes to the PostgreSQL database, which renders immediately for all citizens.

Daily Operations Checklist

Morning Routine

1. Check Dashboard for unread inquiries from remote gewogs.
2. Reconcile overnight donations against banking ledger.
3. Verify that the announcement ribbon shows current campaigns.

Publishing Tenders

1. Open Procurement CMS.
2. Upload tender package PDF with official BHTF tender number.
3. Set closing date — the system will automatically display a countdown.

Code Deployment

Run npm run build before production release to ensure Nitro server and client bundles pass all TanStack type checks.
