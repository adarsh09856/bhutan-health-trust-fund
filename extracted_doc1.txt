🔹 DAY 4: Production SSR 500 Crash Resolution
Problem: In production SSR builds, accessing / triggered a 500 error:
"This page didn't load - Something went wrong on our end. You can try refreshing or head back home."
Root Cause Analysis:
In React 19, react/jsx-dev-runtime is stripped in production.
Vite's default SSR esbuild transpile was referencing jsxDEV, causing an unhandled runtime exception during server render.
Technical Fix Applied:
Configured esbuild: { jsx: "automatic", jsxDev: false } inside vite.config.ts.
Enforced deduplication of react and react-dom in resolve.dedupe.
Verified: HTTP 200 OK across all production SSR routes.
